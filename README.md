Personal Expense Tracker – End-to-End Data Analysis Project:

This project tracks and analyzes personal expense data using four different tools — Excel, SQL, Python, and Power BI — all applied to the same dataset. The goal was to practice the full data analysis workflow: recording data, storing and querying it, processing it programmatically, and visualizing it for insights.

Files in this Repository: FileDescription

Expense_Tracker.xlsx - Excel workbook with raw expense data, Pivot Tables, formulas, and charts to analyze monthly spending by category

Expense_Tracker.sql - SQL script that creates an expense table, loads sample records, and runs queries to filter by category/payment mode and calculate totals

expense_tracker.py - Python script using lists and loops to record, categorize, and summarize daily 

expensesExpense_Tracker.pbix - Power BI dashboard visualizing spending by payment mode (cash, card, UPI, online)

Dataset:

The dataset includes expense records with three fields: category (e.g., food, travel, shopping, bills, entertainment), amount, and payment_mode (cash, card, UPI, online).

Key Insights:

Breakdown of total spending across categories,
Spending patterns by payment mode, highlighting preferred payment habits,
Category-wise and overall expense totals

Skills Demonstrated:

Excel: Pivot Tables, formulas, charts, data organization,
SQL: Table creation, data insertion, filtering, and aggregation queries,
Python: Data handling using lists, loops, and basic logic,
Power BI: Dashboard design and data visualization,
